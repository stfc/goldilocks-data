# Data campaigns

A campaign is one reproducible combination of:

- an electronic-structure code;
- a calculation task;
- a pseudopotential family;
- an ordered parameter schedule;
- submission and convergence rules.

Each campaign directory keeps its README, machine-readable settings,
submission scripts, analysis notebook, and result manifest together.
